# OctoFit Tracker

Project skeleton for the OctoFit Tracker application. Follow the backend and frontend folders to implement the Django backend and React frontend.

Recommended initial steps (from repo root):

1. Create Python virtual environment for backend:

```bash
python3 -m venv octofit-tracker/backend/venv
source octofit-tracker/backend/venv/bin/activate
pip install -r octofit-tracker/backend/requirements.txt
```

2. Create Django project inside `octofit-tracker/backend/` (example):

```bash
python -m django startproject octofit_tracker octofit-tracker/backend/
```

3. Implement frontend app in `octofit-tracker/frontend/` (create with Create React App, Vite, or other tooling).
